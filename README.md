# Projeto Jula

Página única do Projeto Jula: a restauração de uma Chevrolet C10 1977.
Reúne o jogo, o álbum de fotos (47 imagens), as 12 músicas do Audius e a Julacoin.

- Site: https://380run.github.io/Projeto-Jula/
- Jogo: https://380run.github.io/julathetruck/
- Músicas: https://audius.co/jula.thetruck

Para atualizar, edite `index.html` (ou as fotos em `img/`) e envie para a branch `main`. O GitHub Pages republica sozinho em alguns minutos.
