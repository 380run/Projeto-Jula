# Projeto Jula

Página única do Projeto Jula: a restauração de uma Chevrolet C10 1977.
Reúne o jogo, o álbum de fotos (47 imagens), as 12 músicas do Audius e a Julacoin.

## Publicar no GitHub Pages
1. Na conta 380run, crie um repositório público chamado `380run.github.io`.
2. Envie `index.html`, `.nojekyll` e a pasta `img/` (o arquivo `fonte.html` é só a versão de edição e pode ficar de fora).
3. Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. O site fica em https://380run.github.io/ e o jogo continua em https://380run.github.io/julathetruck/
