# Projeto Jula

Página única do Projeto Jula: a restauração de uma Chevrolet C10 1977.
Reúne a história da família, o projeto da restauração, a mecânica em 3D, o jogo, o álbum de fotos (50 imagens), as 12 músicas do Audius, a Julacoin, três planos de fundo para baixar, os dois livros (o do projeto e o infantil *Jula: quase tudo tem conserto*) e a Oficina da Jula. Textos e imagens do projeto vêm do livro "Projeto Jula The Truck", de Bruno Azevedo.

- Site: https://www.julathetruck.com.br/ (também abre por https://380run.github.io/Projeto-Jula/)
- Jogo: https://380run.github.io/julathetruck/
- Músicas: https://audius.co/jula.thetruck

Para atualizar, edite `index.html` (ou as fotos em `img/`) e envie para a branch `main`. O GitHub Pages republica sozinho em alguns minutos.

A seção "Por dentro da Jula" (mecânica em 3D) carrega `js/mecanica.js`, gerado a partir de `fonte/mecanica.src.js` com o three.js embutido.

A **Oficina da Jula** (3D para crianças, com narração) fica em `oficina/` e abre em https://www.julathetruck.com.br/oficina/. O QR code da página 15 do livro infantil aponta para esse endereço: não mude a pasta. Cópia de desenvolvimento no repositório 380run/oficina-da-jula.
